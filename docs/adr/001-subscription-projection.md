# ADR-001: подписка в сервисах через локальную копию

Статус: принято.
Контекст: срок подписки хранит `workspace-service`, а запись должна блокироваться во всех сервисах.
Решение: `workspace-service` публикует `workspace.subscription.changed` (через outbox). Каждый сервис ведёт локальную таблицу `workspace_subscription` и сам блокирует запись по истёкшему сроку.
Отвергнуто: синхронный вызов на каждую запись (связанность и задержка), срок в токене (устаревает до обновления токена).
Последствия: между продлением и блокировкой возможна короткая задержка. Для новых сервисов подписка копируется по тому же шаблону.
