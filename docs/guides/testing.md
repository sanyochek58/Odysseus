# Тесты

Два набора, запускаются отдельно.
- `test` (по умолчанию): юнит на Mockito и `@WebMvcTest`, без контейнеров. Быстрый, его гоняет разработчик: `make test-class`, в конце `make build`.
- `integrationTest`: `@DataJpaTest`, `@SpringBootTest` с Testcontainers (Postgres, Kafka). Тег `@Tag("integration")`, вне `build`. Запускают tester и CI: `make it`.

Контейнеры: один на модуль (статический в общем базовом классе), не на тестовый класс.
Безопасность в тестах: `jwt()` из `spring-security-test` с claim организации и ролями. Реальный Keycloak только в сквозном наборе.
Что покрывать: успех, 400, 404, 403, 409, изоляция тенантов.
Покрытие: JaCoCo 80% на пакет `service`, остальное не считается.
Правила: H2 нельзя, повторный прогон без правок нельзя, имя теста `метод_условие_ожидание`.
