# Worktree агентов

Агенты работают в `.claude/worktrees/agent-*` на временных ветках `worktree-agent-*`. После завершения агента worktree остаются на диске.

Когда вызывать:
- `make wt-clean WT=<имя или путь>` сразу после того, как оркестратор принял результат агента. Безопасно при работающих других агентах.
- `make wt-clean` без WT только когда все агенты остановлены (например, между задачами): чистый worktree работающего агента тоже будет удалён.

Правила: удаляются только worktree без незакоммиченных изменений (без `--force`), грязные пропускаются с сообщением. Временная ветка `worktree-agent-*` удаляется, только если её tip входит в `feature/*` или `fix/*`. Ветки `feature/*`, `fix/*` и `main` не удаляются никогда. В конце выполняется `git worktree prune`.
